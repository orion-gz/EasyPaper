## 검증 범위

- 프로덕션 빌드 및 번역 검증.
- 단위 테스트 270개.
- 실제 문서 오류에서 키보드 포커스와 밝은/어두운 테마 캡처.
- 실제 문서 실패 후 재시도와 삭제 문서 처리, 노트 브리핑 재시도.
- 상태 컴포넌트 샘플을 390px·1280px에서 렌더링해 가로 넘침 확인.
- 모든 API 실패 조합과 운영 서버 장애를 실제로 재현한 것은 아님.
