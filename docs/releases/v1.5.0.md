EasyPaper Desktop 1.5.0 adds margin alignment and formatting tools for memos. The changes below compare **1.4.10 → 1.5.0**.

## English

### Changes since 1.4.10

- Added left and right margin alignment for individual memos, ordered by their document anchors with connectors to the source text.
- Added settings to place right-aligned memos between the original and translation or outside the translation in parallel view, and to extend the page or scroll the memo margin when notes exceed page height.
- Added a memo formatting bar with bold, italic, heading, list, quote, code, and link actions plus a word count; moved memo controls into the bar.
- Preserved memo position and editing focus when detaching from a margin, and kept the original page size when memos are aligned.
- Matched memo control colors to their notes and improved control alignment in Settings.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.5.0은 메모 여백 정렬과 서식 도구를 추가한 릴리스입니다. 아래는 **1.4.10 → 1.5.0** 변경 사항입니다.

### 1.4.10 대비 변경 사항

- 개별 메모를 원문 페이지의 왼쪽 또는 오른쪽 여백에 정렬하는 기능을 추가. 메모를 문서 위치 순서대로 배치하고 원문과 연결선을 유지
- 병렬 보기에서 오른쪽 메모를 원문과 번역문 사이 또는 번역문 바깥에 배치하고, 메모가 페이지 높이를 넘을 때 아래 공간 확장 또는 메모 영역 스크롤을 선택하는 설정을 추가
- 메모에 굵게·기울임·제목·목록·인용·코드·링크 서식 도구와 단어 수 표시를 추가하고 조작 버튼을 서식 표시줄에 정리
- 정렬 해제 시 메모 위치와 편집 포커스를 유지하고, 정렬된 메모가 있어도 원문 페이지 크기를 유지하도록 수정
- 메모 조작 버튼의 색상을 메모 색상에 맞추고 설정 화면 컨트롤의 정렬을 개선

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
