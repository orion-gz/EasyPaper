EasyPaper Desktop 1.6.1 improves Lab setup and model management, remote sync, and document navigation. The changes below compare **1.6.0 → 1.6.1**.

## English

### Changes since 1.6.0

- Improved Lab setup and connection guides, deployment-specific installation and maintenance, with SSH and multiple inference server support.
- Improved shared model downloads, validation and deletion, personal model and CLI settings, Lab admission controls, and member password and account deletion management.
- Added remote library local caching, offline sync, connected desktop details and sync requests; improved account locking, transfer validation and upload recovery.
- Added a collapsible document outline and reference preview cards; fixed PDF rendering in older WebViews and after page jumps.
- Improved library menus, chat code and Markdown layout, inline settings feedback, loading, error and empty states; updated macOS CI runners.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.6.1은 Lab 설치·모델 관리, 원격 동기화, 문서 탐색을 개선한 릴리스입니다. 아래는 **1.6.0 → 1.6.1** 변경 사항입니다.

### 1.6.0 대비 변경 사항

- Lab 설치·연결 가이드 및 환경별 설치·유지보수를 개선하고 SSH와 여러 추론 서버 연결을 지원
- 공유 모델 다운로드·검증·삭제, 개인 모델·CLI 설정, Lab 가입 제한 및 멤버 비밀번호·계정 삭제 관리를 개선
- 원격 라이브러리 로컬 캐시와 오프라인 동기화, 연결된 데스크톱 확인과 동기화 요청을 추가하고 계정 잠금·전송 검증·업로드 복구를 개선
- 접을 수 있는 문서 목차와 참고문헌 미리보기 카드를 추가하고 이전 WebView 및 페이지 이동 후 PDF 렌더링을 수정
- 라이브러리 메뉴, 채팅 코드·Markdown 표시, 설정 입력 피드백, 로딩·오류·빈 상태 UI를 개선하고 macOS CI 러너를 갱신

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
