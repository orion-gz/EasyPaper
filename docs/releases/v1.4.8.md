EasyPaper Desktop 1.4.8 expands Spotlight with document, workspace, reader, and AI actions, and improves the search shortcut. The changes below compare **1.4.7 → 1.4.8**.

## English

### Changes since 1.4.7

- Added Spotlight commands to search and open library documents, list recently read documents, upload PDFs, import URLs, and view running tasks.
- Added commands for sidebar and fullscreen controls, closing and reopening tabs, and selecting light or dark themes.
- Added reader commands for page navigation, zoom and fit width, outline, bookmarks, page memos, and copying document citations.
- Added AI commands to prepare a question, start a fresh conversation, and summarize selected text or the current document, with argument validation and availability checks.
- Improved Ctrl/Cmd+K to toggle search, including with non-Latin keyboard layouts, and added shortcut guidance in Settings and accessibility labels.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.4.8은 Spotlight의 문서·작업 공간·읽기·AI 명령을 확장하고 검색 단축키를 개선한 릴리스입니다. 아래는 **1.4.7 → 1.4.8** 변경 사항입니다.

### 1.4.7 대비 변경 사항

- Spotlight에서 라이브러리 문서 검색·열기, 최근 읽은 문서 조회, PDF 업로드, URL 가져오기, 진행 중인 작업 조회 명령을 추가
- 사이드바·전체 화면 전환, 탭 닫기·다시 열기, 밝은 테마·어두운 테마 지정 명령을 추가
- 페이지 이동, 확대율·너비 맞춤, 목차, 북마크, 페이지 메모, 문서 인용 복사를 지원하는 읽기 명령을 추가
- 질문 작성, 새 대화 시작, 선택한 텍스트 또는 현재 문서 요약을 지원하는 AI 명령을 추가하고 인수 검증·실행 가능 여부 확인을 적용
- 비라틴 문자 키보드 배열에서도 Ctrl/Cmd+K로 검색창을 열고 닫도록 개선하고 설정의 단축키 안내와 접근성 레이블을 추가

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
