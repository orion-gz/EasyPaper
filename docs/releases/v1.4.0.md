EasyPaper Desktop 1.4.0 adds pinnable reference previews and user data export/import. The changes below compare **1.3.0 → 1.4.0**.

## English

### Changes since 1.3.0

- Added pinnable Figure, Table, and Equation previews with multiple floating windows, dragging, keyboard movement, collapsing, and individual closing.
- Added a hover/click preview setting per workspace mode, applied immediately to open document tabs.
- Added ZIP export and import in Settings → Data & System for documents and attachments, translations, chats and comparisons, notes and annotations, folders and graphs, reading history, and user/browser settings.
- Imported documents are added as new copies with remapped IDs and relationships. Shared AI model, parser, and translation prompt settings can be restored optionally; credentials and API keys are excluded.
- Added backup validation and rollback on import failure, retryable browser-settings restoration, and preservation of comparison chats containing permanently deleted documents.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.4.0은 참조 미리보기 고정과 사용자 데이터 내보내기·가져오기를 추가한 릴리스입니다. 아래는 **1.3.0 → 1.4.0** 변경 사항입니다.

### 1.3.0 대비 변경 사항

- 그림·표·수식 미리보기 고정을 추가하고 여러 창 동시 표시·드래그·방향키 이동·접기·개별 닫기를 지원
- 작업 공간 모드별 호버·클릭 미리보기 설정을 추가하고 열린 문서 탭에 즉시 반영
- 설정 → 데이터 및 시스템에서 문서 원본·첨부 파일, 번역, 질문·비교 대화, 메모·주석, 폴더·그래프, 읽기 이력과 사용자·브라우저 설정의 ZIP 내보내기·가져오기를 추가
- 가져온 문서를 ID와 관계를 재매핑한 새 복사본으로 추가하고 공유 AI 모델·파서·번역 프롬프트 설정의 선택적 복원을 지원하며 인증정보·API 키는 제외
- 백업 검증과 가져오기 실패 시 롤백, 브라우저 설정 복원 재시도 및 영구 삭제된 문서를 포함한 비교 대화 보존을 지원

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
