EasyPaper Desktop 1.4.7 expands Spotlight-style search commands, polishes workspace typography and spacing, and makes reference citation reasons specific to the current page. The changes below compare **1.4.6 → 1.4.7**.

## English

### Changes since 1.4.6

- Expanded Spotlight-style search with `/` commands for settings categories, workspace pages, theme switching, logout, and reader actions. Find commands by ID, localized label, or keywords; minimal UI only lists available pages.
- Centered the search dialog, clarified search and command hints, and removed the search input focus border.
- Unified UI typography, theme tokens, and spacing across workspace views, including search results and the task list.
- Simplified reference reading-priority previews to a score and a concise citation reason for the current page. Analysis and cached results are scoped to the requested page, with citation evidence restricted to that page.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.4.7은 Spotlight 스타일 검색 명령을 확장하고 작업 공간의 글꼴·간격을 정리하며 참고문헌 인용 이유를 현재 페이지 문맥에 맞게 개선한 릴리스입니다. 아래는 **1.4.6 → 1.4.7** 변경 사항입니다.

### 1.4.6 대비 변경 사항

- Spotlight 스타일 검색의 `/` 명령을 확장하여 설정 카테고리·작업 공간 페이지 이동, 테마 전환, 로그아웃, 읽기 작업을 지원. 명령 ID·번역된 이름·키워드로 검색할 수 있으며 미니멀 UI에서는 사용 가능한 페이지만 표시
- 검색창을 화면 중앙에 배치하고 검색·명령 안내 문구를 명확히 하며 검색 입력창의 포커스 테두리를 제거
- 검색 결과와 작업 목록을 포함한 작업 공간 화면의 글꼴·테마 토큰·간격을 일관되게 정리
- 참고문헌 읽기 우선순위 미리보기를 점수와 현재 페이지의 간결한 인용 이유로 정리. 요청 페이지별로 분석·캐시를 구분하고 해당 페이지의 인용 근거만 사용하도록 수정

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.

- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
