EasyPaper Desktop 1.6.0 adds remote server connections, two-way library sync, and shared Lab Mode. The changes below compare **1.5.6 → 1.6.0**.

## English

### Changes since 1.5.6

- Connect the desktop app to a remote EasyPaper server or continue using its local data. Server sign-in sessions remain separate from the local account.
- Sync the local and remote libraries in both directions. Preview an initial merge or replacement before applying it, detect conflicts, and resume interrupted syncs. Optional automatic merging runs while the app is open in remote mode with document tabs closed.
- Use shared Lab Mode from the web app or a remotely connected desktop app. Administrators can configure shared AI models and member accounts; personal CLI execution is isolated by account. Server operators must configure the Lab runner before enabling personal CLIs.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.6.0은 원격 서버 연결, 양방향 라이브러리 동기화, 공유 Lab Mode를 추가한 릴리스입니다. 아래는 **1.5.6 → 1.6.0** 변경 사항입니다.

### 1.5.6 대비 변경 사항

- 데스크톱 앱에서 로컬 데이터 사용과 원격 EasyPaper 서버 연결을 선택할 수 있습니다. 서버 로그인 세션은 로컬 계정과 분리됩니다.
- 로컬·원격 라이브러리를 양방향 동기화할 수 있습니다. 최초 병합 또는 한쪽 데이터 대체를 적용 전에 확인하고, 충돌을 감지하며 중단된 동기화를 재개합니다. 선택한 자동 병합은 앱이 원격 모드로 열려 있고 문서 탭이 닫혀 있을 때 실행됩니다.
- 웹 앱과 원격 연결된 데스크톱 앱에서 공유 Lab Mode를 사용할 수 있습니다. 관리자는 공용 AI 모델과 멤버 계정을 설정할 수 있으며, 개인 CLI 실행은 계정별로 격리됩니다. 개인 CLI 사용 전 서버 운영자가 Lab runner를 구성해야 합니다.

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
