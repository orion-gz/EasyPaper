EasyPaper Desktop 1.4.3 smooths PDF zoom and adds Gemini 4 Argon models for Antigravity. The changes below compare **1.4.2 → 1.4.3**.

## English

### Changes since 1.4.2

- Smoothed PDF viewer wheel and pinch zoom with animated previews and deferred rendering after the gesture ends.
- Improved zoom consistency across wheel event units and preserved the current rendered scale when starting a zoom gesture.
- Added Gemini 4 Argon Medium and High to the Antigravity model list.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.4.3는 PDF 확대/축소를 개선하고 Antigravity용 Gemini 4 Argon 모델을 추가한 릴리스입니다. 아래는 **1.4.2 → 1.4.3** 변경 사항입니다.

### 1.4.2 대비 변경 사항

- PDF 뷰어의 휠·핀치 확대/축소에 애니메이션 미리보기를 적용하고 제스처 종료 후 렌더링하도록 개선
- 휠 이벤트 단위별 확대/축소 동작을 일관되게 처리하고 제스처 시작 시 현재 렌더링 배율을 반영
- Antigravity 모델 목록에 Gemini 4 Argon Medium·High를 추가

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
