EasyPaper Desktop 1.4.6 adds reference reading-priority analysis and pinned PDF region captures, and fixes PDF cache clearing. The changes below compare **1.4.5 → 1.4.6**.

## English

### Changes since 1.4.5

- Added reading-priority analysis in reference previews to help decide which cited works are useful for understanding the current document. It shows a score, citation roles and reasons, supporting excerpts, and source-page links. Automatic analysis can be enabled in Settings; it is off by default.
- Added up to five pinned captures of selected PDF regions. Move, resize, collapse, or close each capture, or jump to its source page. PDF region selection and capture controls support keyboard use.
- Fixed PDF extraction-cache clearing so existing translations are preserved.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.4.6은 참고문헌 읽기 우선순위 분석과 PDF 영역 고정 캡처를 추가하고 PDF 캐시 삭제 문제를 수정한 릴리스입니다. 아래는 **1.4.5 → 1.4.6** 변경 사항입니다.

### 1.4.5 대비 변경 사항

- 참고문헌 미리보기에서 현재 문서를 이해하는 데 도움이 되는 읽기 우선순위를 분석하는 기능을 추가했습니다. 점수, 인용 역할과 이유, 근거 문맥, 원문 페이지 이동을 제공합니다. 설정에서 자동 분석을 켤 수 있으며 기본값은 꺼짐입니다.
- PDF에서 선택한 영역을 최대 5개까지 화면에 고정할 수 있습니다. 각 캡처를 이동·크기 조절·접기·닫기하고 원본 페이지로 이동할 수 있습니다. 키보드로 영역 선택과 캡처 조작도 가능합니다.
- PDF 추출 캐시를 삭제할 때 기존 번역본이 함께 삭제되지 않도록 수정했습니다.

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
