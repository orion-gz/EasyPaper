EasyPaper Desktop 1.6.5 improves large-document performance, defers heavy PDF extraction until open, adds lazy figure overlays and on-demand textbook figure lookup, and introduces a model reasoning effort control. The changes below compare **1.6.4 → 1.6.5**.

## English

### Changes since 1.6.4

- Load figure overlays lazily around the active reading page, recover textbook figure labels from captions, and resolve textbook figures on demand when clicked.
- Defer PDF text and Marker/MinerU extraction from upload to first document open, separate AI classification from upload, and report extraction progress in the viewer loading screen.
- Improve Tauri desktop viewer scrolling and large-document rendering performance, and unify sentence highlight boxes to prevent symbol or decimal splits.
- Add a model reasoning effort slider, align the reasoning popover and model menu, and refine translation prompt chips, localized prompt displays, and translation setup layout.
- Fix Windows remote upload content-length handling, upload ID cleanup, and polling resume, and make the Korean README default with a link to the English README.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.6.5는 대형 문서 렌더링 성능 개선, 문서 열기 시점 지연 추출, 그림 오버레이 지연 로딩 및 교재 그림 온디맨드 검색, 모델 추론 강도 조절 기능을 추가합니다. 아래는 **1.6.4 → 1.6.5** 변경 사항입니다.

### 1.6.4 대비 변경 사항

- 읽는 페이지 주변의 그림 오버레이를 지연 추출하고, 캡션에서 교재 그림 번호를 복구하며 클릭 시 온디맨드로 그림을 찾도록 개선
- 업로드 시점의 PDF 텍스트·Marker·MinerU 추출을 첫 문서 열기 시점으로 지연하고, AI 분류를 분리해 뷰어 로딩 화면에 추출 진행 상태를 표시
- Tauri 데스크탑 뷰어 스크롤과 대형 문서 렌더링 성능을 개선하고, 문장 강조 박스를 통합해 기호·소수점 분리 현상을 수정
- 모델 추론 강도(reasoning effort) 슬라이더를 추가하고 추론 팝오버·모델 메뉴 정렬, 번역 프롬프트 칩, 다국어 프롬프트 표시 및 번역 설정 레이아웃을 개선
- Windows 원격 업로드의 Content-Length 처리, 업로드 ID 정리, 폴링 재개를 수정하고 한국어 README를 기본으로 연결

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.
