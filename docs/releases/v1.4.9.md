EasyPaper Desktop 1.4.9 fixes MinerU installation and PDF parser selection after cache resets, and improves reading settings and selection tooltips. The changes below compare **1.4.8 → 1.4.9**.

## English

### Changes since 1.4.8

- Fixed MinerU installation in packaged desktop apps by bundling the source-only ANTLR dependency as a wheel and using the compatible MinerU 2.x pipeline. Installation results and error logs remain visible after settings refreshes.
- Fixed PDF extraction-cache resets to apply the selected parser to text and figure, table, and equation regions. Marker and MinerU image extraction uses their managed environments, including after restarting the app.
- Moved reading preferences into the Viewer settings category.
- Kept selected-text tooltip action labels on one line.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.4.9는 MinerU 설치와 캐시 초기화 후 PDF 파서 적용 오류를 수정하고 읽기 설정 및 선택 툴팁을 개선한 릴리스입니다. 아래는 **1.4.8 → 1.4.9** 변경 사항입니다.

### 1.4.8 대비 변경 사항

- 데스크톱 앱에 소스 배포 전용 ANTLR 의존성을 wheel로 포함하고 호환되는 MinerU 2.x 파이프라인을 사용하여 MinerU 설치 오류를 수정. 설정 새로고침 후에도 설치 결과와 오류 로그를 유지
- PDF 추출 캐시 초기화 후 선택한 파서를 텍스트와 그림·표·수식 영역에 적용하도록 수정. 앱 재시작 후에도 Marker·MinerU의 관리 환경에서 이미지 영역을 추출하도록 개선
- 읽기 설정을 뷰어 설정 카테고리로 이동
- 선택한 텍스트의 툴팁 작업 이름이 한 줄로 표시되도록 수정

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
