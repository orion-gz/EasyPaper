EasyPaper Desktop 1.2.0 focuses on integrating workspace tabs with desktop window controls. The changes below compare **1.1.0 → 1.2.0**.

## English

### Changes since 1.1.0

- Integrated workspace tabs and window controls into one full-width top bar in the Windows and macOS desktop apps; moved the sidebar below the tab bar.
- Added minimize, maximize/restore, and close buttons on Windows, and retained native traffic-light controls on macOS with an overlay title bar.
- Added window dragging from empty areas and double-click maximization while preserving tab selection, closing, and drag-to-reorder behavior.
- Kept window controls available on the login screen, after session expiry, and while the packaged backend starts or reports a startup error.
- Adjusted the title bar and native-button spacing for UI scale changes and macOS full screen; prevented the search input from covering Windows controls.
- Added English/Korean accessible labels, synchronized maximize/restore indicators with native window state, and added Chromium/WebKit regression coverage.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.2.0은 작업 탭과 데스크톱 창 조작 버튼의 통합을 중심으로 개선한 릴리스입니다. 아래는 **1.1.0 → 1.2.0** 변경 사항입니다.

### 1.1.0 대비 변경 사항

- Windows·macOS 데스크톱 앱의 작업 탭과 창 조작 버튼을 창 전체 너비의 상단 바 한 줄로 통합하고, 사이드바를 탭 바 아래로 배치
- Windows에 최소화·최대화/복원·닫기 버튼을 추가하고, macOS는 Overlay 제목 표시줄에서 기본 신호등 버튼을 유지
- 빈 영역 창 드래그와 더블클릭 최대화를 지원하면서 탭 선택·닫기·드래그 순서 변경 동작을 유지
- 로그인 화면, 세션 만료 후 화면, 패키징된 백엔드의 시작 대기·시작 오류 화면에서도 창 조작을 지원
- UI 배율 변경과 macOS 전체 화면에 맞춰 제목 표시줄·네이티브 버튼 여백을 조정하고, 검색 입력이 Windows 창 버튼을 가리는 문제를 방지
- 영어/한국어 접근성 레이블과 네이티브 최대화/복원 상태 동기화를 추가하고, Chromium/WebKit 회귀 테스트를 추가

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
