EasyPaper Desktop 1.4.4 adds configurable reading tools, workspace search, and a task progress center. The changes below compare **1.4.3 → 1.4.4**.

## English

### Changes since 1.4.3

- Added per-document reading preference restoration and a return action after jumping to references, figures, or cited pages.
- Added configurable quick actions for translating and explaining selected text in PDF and article documents, with keyboard selection support.
- Added focus reading with original-only, translation-only, and side-by-side views, restoring the previous panel layout when leaving focus mode.
- Added workspace search for documents, memos, and questions, plus a command palette accessible with Ctrl/Cmd+K.
- Added a configurable task progress center for viewing document processing progress, opening documents, and retrying failed tasks.
- Added individual settings for the new reading features and improved reader interactions, search cancellation, and search/task query limits.
- Fixed citation previews to respect click mode, moved updates to About & System settings, and kept the theme preview aligned in Settings.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.4.4는 읽기 편의 기능, 작업 공간 통합 검색과 작업 진행 센터를 추가한 릴리스입니다. 아래는 **1.4.3 → 1.4.4** 변경 사항입니다.

### 1.4.3 대비 변경 사항

- 문서별 읽기 설정 복원과 참조·그림·인용 페이지로 이동한 뒤 이전 읽기 위치로 돌아가는 기능을 추가
- PDF·기사 문서에서 선택한 텍스트를 번역·설명하는 빠른 작업과 키보드 선택 지원을 추가
- 원문만·번역만·나란히 보기를 지원하는 집중 읽기 모드를 추가하고 종료 시 기존 패널 배치를 복원
- 문서·메모·질문을 찾는 작업 공간 통합 검색과 Ctrl/Cmd+K로 여는 명령 팔레트를 추가
- 문서 처리 진행 상황 확인·문서 열기·실패한 작업 재시도를 지원하는 작업 진행 센터를 추가
- 새 읽기 기능별 설정을 추가하고 읽기 화면 상호작용·검색 취소·검색 및 작업 조회 비용 제한을 개선
- 인용 미리보기가 클릭 모드 설정을 따르도록 수정하고 업데이트를 정보 및 시스템 설정으로 이동하며 설정 화면 테마 미리보기 정렬을 수정

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
