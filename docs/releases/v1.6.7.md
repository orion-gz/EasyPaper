EasyPaper Desktop 1.6.7 introduces a minimalist dual-archetype UI redesign across the workspace and viewer, polishes UI copy, and improves OCR fallback handling. The changes below compare **1.6.6 → 1.6.7**.

## English

### Changes since 1.6.6

- Redesign workspace (dashboard, library, reading history, AI chats, notes, research graph) and viewer with a minimalist dual-archetype UI and add a UI style selector in Settings.
- Polish English and Korean UI copy for clarity and fix Korean grammar.
- Move the onboarding guide button to the Info tab in Settings with fixed spacing, and hide horizontal and vertical scrollbars in the dashboard.
- Place the extraction status dot to the left of the refresh button and fall back to Marker OCR when `llama-server` is missing.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.6.7은 워크스페이스와 뷰어 전반에 미니멀리스트 듀얼 아키타입 UI 리디자인을 적용하고, UI 문구를 다듬었으며, OCR 폴백 처리를 개선했습니다. 아래는 **1.6.6 → 1.6.7** 변경 사항입니다.

### 1.6.6 대비 변경 사항

- 워크스페이스(대시보드·라이브러리·읽기 기록·AI 채팅·노트·연구 그래프)와 뷰어 전반에 미니멀리스트 듀얼 아키타입 UI 리디자인 및 설정의 UI 스타일 선택 기능을 추가
- 한국어·영어 UI 문구를 다듬어 가독성과 맞춤법을 개선
- 온보딩 안내 버튼을 설정의 정보 탭으로 이동하고 여백 스타일을 수정하며, 대시보드의 가로·세로 스크롤바를 숨김
- 추출 상태 표시 점을 새로고침 버튼 왼쪽으로 배치하고, `llama-server`가 없을 때 Marker OCR로 폴백하도록 수정

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
