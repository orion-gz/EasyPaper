EasyPaper Desktop 1.3.0 adds custom themes and a minimal workspace UI, and improves reading, library, notes, and chat reliability. The changes below compare **1.2.1 → 1.3.0**.

## English

### Changes since 1.2.1

- Added separate light/dark custom themes with named presets, editable colors, settings previews, and synchronized document-frame colors.
- Added a minimal workspace UI mode and refined workspace spacing, cards, and theme previews.
- Preserved reading history across tabs; fixed PDF text selection, Focus mode markers, and Easy English source matching.
- Improved library search cancellation and response ordering, kept folders visible in empty libraries, and reported partial failures in bulk actions.
- Scoped trash emptying to the current workspace mode and contained keyboard focus within confirmation dialogs.
- Prevented duplicate note event handlers across visits; honored the notes briefing target language and enabled retrying failed briefings.
- Preserved chat input during IME composition when pressing Enter and refreshed the API model catalog.
- Improved Linux release packaging recovery and draft-release RPM uploads.

### Platform notes

- **Windows**: Window controls are custom buttons. The Windows 11 Snap Layout menu on maximize-button hover is not included in this release.
- **macOS**: Native traffic-light controls are retained. The macOS download is for Apple Silicon (arm64).
- **Linux**: `.deb` and `.rpm` packages remain available; the title-bar integration applies to Windows and macOS.

### Installation

- Download the installer for your platform below, or update from the desktop app's settings.
- **macOS**: The app is not code-signed or notarized. If macOS blocks opening it, run `xattr -cr /Applications/EasyPaper.app` after placing it in Applications, then reopen it.
- **Windows**: If SmartScreen displays a warning, select **More info → Run anyway**.
- **Linux**: Install the `.deb` or `.rpm` package for your distribution.

## 한국어

EasyPaper Desktop 1.3.0은 커스텀 테마와 미니멀 작업 공간 UI를 추가하고 읽기·라이브러리·메모·채팅의 안정성을 개선한 릴리스입니다. 아래는 **1.2.1 → 1.3.0** 변경 사항입니다.

### 1.2.1 대비 변경 사항

- 라이트·다크 모드별 커스텀 테마, 테마 프리셋·색상 편집·설정 미리보기 및 문서 프레임 색상 동기화를 추가
- 미니멀 작업 공간 UI 모드를 추가하고 작업 공간 여백·카드·테마 미리보기를 개선
- 탭 간 읽기 기록을 유지하고 PDF 텍스트 선택·집중 모드 표시·Easy English 원문 대응을 수정
- 라이브러리 검색 취소·응답 순서 처리를 개선하고 빈 라이브러리에서도 폴더를 표시하며 일괄 작업의 부분 실패를 안내
- 휴지통 비우기 범위를 현재 작업 공간 모드로 제한하고 확인 대화상자 내부에 키보드 포커스를 유지
- 메모 화면 재방문 시 이벤트 중복 등록을 방지하고 브리핑 대상 언어를 반영하며 실패한 브리핑 재시도를 지원
- IME 조합 중 Enter 입력으로 채팅 내용이 전송되는 문제를 수정하고 API 모델 목록을 갱신
- Linux 릴리스 패키징 복구와 초안 릴리스의 RPM 업로드를 개선

### 플랫폼별 안내

- **Windows**: 창 조작 버튼은 커스텀 버튼이며, Windows 11 최대화 버튼 호버 시 Snap Layout 메뉴는 이번 릴리스에 포함되지 않습니다.
- **macOS**: 기본 신호등 버튼을 유지합니다. macOS 다운로드는 Apple Silicon(arm64)용입니다.
- **Linux**: `.deb`와 `.rpm` 패키지를 제공합니다. 제목 표시줄 통합은 Windows와 macOS에 적용됩니다.

### 설치 안내

- 아래에서 운영체제에 맞는 설치 파일을 다운로드하거나, 데스크톱 앱 설정에서 업데이트하세요.
- **macOS**: 앱은 서명·공증되지 않았습니다. 실행이 차단되면 응용 프로그램 폴더로 옮긴 뒤 `xattr -cr /Applications/EasyPaper.app`을 실행하고 다시 여세요.
- **Windows**: SmartScreen 경고에서 **추가 정보 → 실행**을 선택하세요.
- **Linux**: 배포판에 맞는 `.deb` 또는 `.rpm` 패키지를 설치하세요.
