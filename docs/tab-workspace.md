# 탭 워크스페이스

`ask/UI/renew.png`의 고정 사이드바, 상단 탭, 문서 목차, 본문, 우측 도구 패널 구성을 적용한다.

## 화면 구성

- 사이드바에서 Dashboard, Library, AI Chats, Notes, Reading History, Research Graph를 열면 페이지별 탭 하나를 생성하거나 기존 탭을 활성화한다. Settings는 모달로 유지한다.
- 문서는 ID별로 탭 하나를 사용한다. 탭 닫기, 드래그 순서 변경, 전체 탭 선택, 새 탭의 문서 열기·추가 메뉴를 제공한다.
- 탭에서 방향키/Home/End로 이동, Delete로 닫기, Alt+방향키로 순서를 변경한다.
- 문서 왼쪽은 Outline/Thumbnails, 중앙은 원문·번역·병렬 읽기, 오른쪽은 AI Chat/Notes/Annotations로 구성한다. 병렬 읽기는 양쪽 패널을 접고, 종료하면 이전 패널 상태를 복원한다.
- 하단 도구는 페이지 이동, 확대·축소, Focus, 전체 화면을 제공한다. 좁은 화면에서는 목차와 AI 패널을 겹쳐 표시하고 동시에 하나만 연다.

## 상태와 수명

`workspaceTabsStore.js`는 탭 순서, 활성 탭, 문서 제목, 읽기 위치·배율·패널 설정을 관리한다. 저장 키는 서버 origin, 사용자, 연구/일반 모드로 구분한다. 채팅 내용, 입력 초안, 스트림, PDF 데이터는 탭 복원 저장소에 기록하지 않는다.

`workspaceTabs.js`가 화면 셸과 페이지 탐색을 소유한다. 페이지의 스크롤을 유지하고, Library/Notes/History/Dashboard/AI Chats는 재진입 시 데이터를 다시 읽는다. Library 검색·필터·선택 및 AI Chats 보기 설정을 유지한다. 기존 URL 해시와 브라우저 뒤로/앞으로 이동을 지원한다.

각 문서는 동일 출처 iframe에서 기존 뷰어를 실행한다. 기존 뷰어의 DOM ID, PDF worker, 모듈 상태, 채팅·번역 요청을 문서별로 격리한다. `documentWorkspaceRuntime.js`의 런타임과 부모 셸은 제한된 메서드와 출처·발신 창을 검증하는 메시지로 통신한다.

- 탭 전환 전에 읽기 위치와 보류 중인 주석 저장을 처리한다. 저장 실패 시 전환을 중단하고 오류를 표시한다.
- 비활성 문서는 읽기 시간을 누적하지 않고 PDF 캔버스·관찰자·썸네일 렌더링을 해제한다. 다시 활성화하면 읽기 위치에서 렌더링을 재개한다.
- 탭을 바꾸거나 닫아도 진행 중인 채팅·번역은 원래 문서에서 계속된다. 닫힌 문서의 런타임은 요청이 끝나면 제거한다. 열린 비활성 탭은 작업 상태를 표시한다.
- 재시작 후에는 탭 메타데이터를 복원하고 활성 문서부터 지연 로드한다. 문서 접근 권한이 없거나 삭제되었다면 해당 탭을 제거한다. 일시적인 로드 실패는 재시도를 제공한다.
- UI 배율은 문서 안에서 적용하고 iframe 외곽은 화면 좌표를 유지한다. 테마·언어·배율 변경을 문서 런타임에 전달한다.

## CSP

웹 서버와 데스크톱 CSP의 `frame-ancestors`를 `'self'`로 설정한다. 내부 문서 런타임을 허용하기 위한 명시적으로 승인된 변경이며 외부 출처에서 앱을 임베딩하는 것은 허용하지 않는다.

## 검증과 한계

탭 저장소 단위 테스트와 `workspace-tabs.spec.js`에서 복원, 중복 방지, 문서별 초안, 페이지 탭, 키보드 탐색, 패널, 요청 중 닫기, 캔버스 해제, 로드 실패 처리를 다룬다. 기존 뷰어 회귀 테스트는 `activeReader`/`evaluateReader`를 통해 활성 문서를 대상으로 실행한다.

비활성 문서의 캔버스는 해제하지만 PDF 문서 핸들과 모듈은 탭을 닫을 때까지 유지한다. 많은 문서를 열면 메모리 사용량이 증가할 수 있다. 진행 중인 요청은 앱 전체 종료 후에는 이어지지 않는다. 탭 복원은 현재 기기의 브라우저 저장소를 사용한다.
